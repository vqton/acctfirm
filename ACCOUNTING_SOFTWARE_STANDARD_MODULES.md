## 4. Review Analysis — Key Differentiators

### MISA
**Strengths:** Easiest to use, fastest deployment, largest ecosystem (40+ apps), AI assistant (AVA), strongest tax/GDT integration, largest support network, regular free updates.
**Weaknesses:** Limited deep customization, complex multi-company consolidation requires higher-tier plans.
**Best for:** SMEs, service companies, startups, accounting service firms.

### Fast Accounting
**Strengths:** Fastest data processing at scale, deep inventory costing (manufacturing/construction), highly customizable reports, good for high-volume transaction businesses.
**Weaknesses:** UI less intuitive (dated), requires training, narrower ecosystem, limited HR/CRM.
**Best for:** Manufacturing, construction, trading companies with high transaction volume and complex costing.

### Bravo (ERP)
**Strengths:** Most customizable, true ERP, strongest for complex multi-department workflows, best for manufacturing with BOM/QC/equipment management.
**Weaknesses:** Highest cost, longest deployment, requires IT support, overkill for small businesses.
**Best for:** Large enterprises, manufacturing groups, multi-company consolidation, complex processes.

## 6. Summary — Standard Architecture Must-Haves

### By Accounting Domain

```
Cash & Bank         -> Receipt, Payment, Transfer, Bank Reconciliation, Petty Cash
Purchasing (AP)     -> PO, Receipt, Invoice, Supplier Aging, Payment, Return
Sales (AR)          -> SO, Delivery, Invoice, Customer Aging, Receipt, Return
Inventory           -> Multi-warehouse, FIFO/WAC/Specific ID, Count, Adjustment, Provision
Fixed Assets        -> Depreciation, Increase/Decrease/Transfer/Liquidation
CCDC (Tools)        -> Allocation, Amortization, Tracking
Payroll & HR        -> Salary, Insurance, PIT, Timesheet, SI Declaration
Production & Cost   -> BOM, WIP, Normal/Abnormal Cost, Unit Cost
Tax                 -> VAT, CIT, PIT, License Tax, Import Tax, E-Filing
GL & Reporting      -> Journal, Ledger, FS, Trial Balance, Closing
Management Reports  -> P&L, Cash Flow, Budget, KPIs, Dashboards
System              -> RBAC, Audit Log, Multi-Currency, Multi-Branch, API
```

### By Regulatory Layer

```
Circular 99/2025/TT-BTC    -> Chart of Accounts, Books, Forms, Reports
VAS Standards               -> VAS 02/10/14/21/23 etc.
Tax Law                     -> VAT, CIT, PIT, License Tax, Import/Export Tax
Decree 123 (E-Invoice)      -> Electronic Invoice Issuance & Processing
Decree 70/2025 (Cash Reg.)  -> POS-connected e-invoice
Social Insurance Law        -> BHXH, BHYT, BHTN rates & declarations
```

This is the complete standard feature set that any Vietnamese accounting software must implement to be market-viable.
