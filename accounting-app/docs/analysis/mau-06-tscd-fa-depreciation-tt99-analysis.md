## TỔNG QUAN

Mẫu 06-TSCĐ là chứng từ kế toán bắt buộc theo TT 99, dùng để:

1. **Tính** số khấu hao TSCĐ phải trích trong tháng
2. **Phân bổ** số khấu hao vào chi phí theo bộ phận sử dụng (TK 623, 627, 641, 642, 241, 242, 335)
3. **Đối chiếu** với sổ kế toán (Có TK 214 — Hao mòn TSCĐ)
4. **Căn cứ** tính giá thành sản phẩm, dịch vụ

## CƠ SỞ PHÁP LÝ KHẤU HAO TSCĐ

### Nguyên tắc trích khấu hao (TT 45/2013/TT-BTC, sửa đổi bởi TT 147/2016)

1. **Tất cả TSCĐ hiện có đều phải trích KH**, trừ:
   - TSCĐ đã KH hết nhưng vẫn SD
   - TSCĐ KH chưa hết bị mất
   - TSCĐ không thuộc quyền sở hữu DN (trừ thuê tài chính)
   - TSCĐ không được theo dõi trong sổ kế toán
   - TSCĐ phúc lợi (nhà nghỉ ca, nhà ăn, nhà để xe...)
   - TSCĐ viện trợ không hoàn lại
   - TSCĐ vô hình là quyền SD đất lâu dài

2. **Phương pháp khấu hao** (3 phương pháp):
   - **Đường thẳng** (straight-line) — phổ biến nhất
   - **Số dư giảm dần có điều chỉnh** (declining balance)
   - **Theo số lượng, khối lượng sản phẩm** (units of production)

3. **Thời gian KH**: DN tự quyết định theo khung TT 45, thông báo cho cơ quan thuế

4. **Nhất quán**: Phương pháp đã chọn không được thay đổi (trừ 1 lần khi có thay đổi cách thức SD)

### Cách tính

```
Số KH tháng này = Số KH tháng trước 
                 + Số KH tăng trong tháng 
                 - Số KH giảm trong tháng
```

Với:
- **KH tăng**: TSCĐ mới mua, XDCB hoàn thành bàn giao → trích KH từ tháng tiếp theo
- **KH giảm**: TSCĐ thanh lý, nhượng bán, điều chuyển → ngừng trích KH từ tháng tiếp theo
- **KH tạm dừng**: TSCĐ không SD, chờ thanh lý → vẫn phải trích KH (nếu chưa hết KH)

### Hạch toán

```
Nợ TK 623, 627, 641, 642, 241, 242, 335 (tùy bộ phận SD)
Có TK 214 — Hao mòn TSCĐ
```

## USE CASES

### UC-01: Tính khấu hao hàng tháng (Monthly Depreciation Calculation)

**Actor:** Kế toán TSCĐ  
**Trigger:** Đầu tháng / khi có biến động TSCĐ  
**Precondition:** TSCĐ đã được ghi nhận, có phương pháp KH, thời gian SD, nguyên giá

**Happy Path:**
1. System load all active TSCĐ
2. For each asset: calculate monthly depreciation based on method (straight-line/declining balance/units of production)
3. Group by cost center/department
4. Generate Mẫu 06-TSCĐ report
5. Allow review before posting

**Alternative Path A1 — TSCĐ mới trong tháng:**
1. Asset acquired this month → start depreciation **next month** (TT 45)
2. Display in row "II. Số KH TSCĐ tăng trong tháng"
3. Include in "IV. Số KH trích tháng này" for **next** month

**Alternative Path A2 — TSCĐ thanh lý trong tháng:**
1. Asset disposed this month → stop depreciation **this month** (TT 45)
2. Display in row "III. Số KH TSCĐ giảm trong tháng"
3. Exclude from "IV. Số KH trích tháng này"

**Alternative Path A3 — Fully depreciated asset:**
1. Asset accumulated depreciation = original cost → zero monthly depreciation
2. Still display in list with "Đã KH hết" status
3. Not included in calculation

**Failure F1 — No active assets:**
1. System has 0 active TSCĐ
2. → Warning: "Không có TSCĐ đang sử dụng"
3. → Allow manual override for new companies

**Failure F2 — Missing depreciation method:**
1. Asset has no depreciation method configured
2. → Error: "TSCĐ [code] chưa có phương pháp khấu hao"
3. → Block calculation until fixed

### UC-02: Phân bổ khấu hao theo bộ phận

**Actor:** Kế toán TSCĐ  
**Trigger:** Sau khi tính KH tháng  
**Precondition:** Asset→Department mapping exists

**Happy Path:**
1. Load calculated depreciation total
2. Distribute to cost accounts based on department:
   - Production → TK 627
   - Sales → TK 641
   - Management → TK 642
   - Construction → TK 241
   - Prepaid → TK 242
   - Accrued → TK 335
3. Verify total Dr = total Cr (invariant)
4. Generate journal entry:
   ```
   Nợ 627, 641, 642, 241, 242, 335 / Có 214
   ```

**Alternative Path B1 — Department changed mid-month:**
1. Asset transferred between departments
2. → Prorate: old dept gets (days/30), new dept gets remainder
3. → Both departments show partial amounts

## DATA FLOW

```
fixed_assets (master data)
  ├── asset_code, name, category
  ├── original_cost, depreciation_method, useful_life
  ├── accumulated_depreciation, residual_value
  └── department_id, status (active/disposed/paused)

depreciation_schedules (per asset per month)
  ├── asset_id, period (YYYY-MM)
  ├── depreciation_amount
  ├── accumulated_to_date
  └── status (calculated/posted/adjusted)

fixed_asset_transactions (events)
  ├── type: acquisition/disposal/transfer/revaluation
  ├── asset_id, date, amount
  └── reference to related documents

department_cost_centers (mapping)
  ├── department_id → debit_account (627, 641, 642...)
  └── allocation_percentage (if shared)

=== Monthly Run ===

1. Load all active assets
2. For each asset:
   ├── is new this month? → skip, start next month
   ├── is disposed this month? → stop this month
   ├── is paused? → skip
   ├── is fully depreciated? → amount = 0
   └── calculate monthly depreciation
3. Group by department → debit accounts
4. Generate Mẫu 06-TSCĐ
5. Generate journal entry (Dr 627/641/642 / Cr 214)
6. Update depreciation_schedules
7. Update accumulated_depreciation on fixed_assets
```
